# 計算じゃんけん（CALC // JANKEN）

じゃんけんで出た数字を **変数に代入** して計算する、サイバー空間風の計算トレーニングゲームです。
小学1年生から中学3年生までの計算を、5段階の難易度で体験できます。

**▶ 遊ぶ：** https://yunakonnodh.github.io/calc-janken/

![対戦画面](battle.png)

---

## どんなアプリ？

コンピューターとじゃんけんをすると、自分とCPUにそれぞれ数字が配られます。
`me`（自分の数字）と `cpu`（CPUの数字）を使った計算式に答え、**10問を解くスピード** をランキングで競います。

```js
let me  = 7;   // あなた ✊
let cpu = 4;   // CPU ✌️
me × cpu = ?
```

### じゃんけんの結果で計算が変わる

| 結果 | 計算 |
|---|---|
| 勝ち | × かけ算 |
| 負け | ÷ わり算 |
| あいこ | ＋ たし算 または − ひき算 |

---

## 遊び方

1. **ログイン**：ユーザー名と難易度を選びます
2. **ルール説明**：勝ち・負け・あいこの計算が3秒ずつ表示 →「ARE YOU READY?」で **YES!** を押すとスタート（**NOT YET** で説明をもう一度）
3. **手札を組む**：グー・チョキ・パー合わせて10枚の手札を自分で振り分けます（CPUの手札は公開）
4. **対戦**：手を出すと「じゃん・けん・ぽん！」→ 勝敗と数字が表示。すぐに答えを入力できます（計算式は3秒後に表示）
5. **結果**：かかった秒数で表彰台ランキングに登録されます

## 難易度（5段階）

| 段階 | 内容 | 制限時間 |
|---|---|---|
| 小1-2 はじめての計算 | たし算・ひき算（2けたまで）／九九／九九の逆のわり算 | 20秒 |
| 小3-4 大きな数と小数 | 3けたの計算／小数のたし算・ひき算／2〜3けた×1けた／小数×整数／2けたでわるわり算 | 25秒 |
| 小5-6 小数と分数 | 通分する分数のたし算・ひき算／小数×小数・小数÷小数／分数×分数・分数÷分数 | 40秒 |
| 中1 正負の数 | 正負の数の四則計算／累乗（(−3)² と −3² のちがい）／負の分数 | 30秒 |
| 中2-3 平方根と式の値 | 平方根の四則計算（√12 → 2√3）／正負の数・分数・累乗の組み合わせ | 40秒 |

- 分数は `3/4`、小数は `0.75`、平方根は `3√2`（PCでは `3r2` と入力）のように答えます
- 分数は約分、平方根は√の中を簡単にしないと正解になりません（ヒントが表示されます）

## ルール・スコア

- **タイム** ＝ 10問の回答時間の合計 ＋ ミス1問につき10秒
- ランキングは難易度ごと・各プレイヤーの自己ベストで集計
- 1〜3位はスポットライトの当たる表彰台、4位以降はリストで表示

### 手札制で「どの手を出すか」に作戦が生まれる

- 自分の手札10枚の配分は自由（例：グー4・チョキ3・パー3）
- CPUの手札は公開。CPUは残りの手札からランダムに出すので、**終盤ほど相手の手が読める**
- 「CPUにグーが多いからパーを多めに入れて×を狙う」「わり算が得意だからあえて負ける手を入れる」などの戦略が立てられます

## 工夫した点

- **サイバー空間風UI**（テーマカラーは白×赤）：グリッドの床・スキャンライン・グリッチ文字
- **VSバトル演出**：掛け声、判定スタンプ（WIN! / LOSE / DRAW）、画面の揺れ・フラッシュ・火花、負けた側に K.O.
- **分数・平方根・累乗を教科書のような形で表示**（分数は縦書き、√は横線つき）
- **答えを正確に判定**：小数の誤差が出ないよう、分数（有理数）と平方根を自前で計算
- **スマホ対応**：画面下に固定したテンキーで、スクロールせずに回答できる
- **日本語入力のままでもOK**：全角数字を自動で半角に変換、IMEの変換確定中の Enter にも対応
- **効果音**：Web Audio API で音を生成（音声ファイルなし）
